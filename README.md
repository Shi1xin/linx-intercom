# 灵矽同频

面向司机的无屏全双工群语音对讲应用。设备通过 NFC 碰一碰创建或加入房间，利用移动网络实时通话，并支持语音切换房间

当前阶段：产品与架构设计待评审，仓库基础结构已建立

## 阅读入口

- [产品与架构设计](docs/product-design.md)：产品交互、NFC 入房规则、全双工音频架构和评审决策
- [实施方案](docs/implementation-plan.md)：模块分工、开发阶段、设备准备和验收步骤

## 技术组成

- 设备端：ESP-IDF 固件、ESP-WebRTC、音频处理、NFC 读卡和固定语音命令
- 房间控制：设备身份、标签入口、房间关系和信令协调
- 音频服务：Janus AudioBridge 为每位参与者生成其他成员的混合音频

## 开发设备

- X-Atom 样机：4G、麦克风、扬声器、电池
- ESP32 面包板：Wi-Fi、麦克风、扬声器、USB 供电
- 电脑浏览器：开发调试对端及第三位测试参与者

两个硬件终端通过各自的网络连接同一个云端语音房间。运行入口和构建命令随对应模块落地补充
